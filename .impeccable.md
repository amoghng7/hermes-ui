# Hermes UI — Design Context

## Design Context

### Users
Product teams and knowledge workers delegating complex, multi-step tasks to AI agent swarms. They care about outcomes, not implementation details — they want to understand what agents are doing, what's been decided, and what's next. Context: focused work sessions where they need power without friction. Not researchers or ML engineers; people who use AI to get real work done faster.

### Brand Personality
**Intelligent · Precise · Calm**

Voice: Confident but never loud. Every word and visual element earns its place. Hermes should feel like a trusted co-worker who can orchestrate a hundred things at once — never a toy, never a generic assistant.

Tone: Technical and professional, never whimsical or playful. Sparse, purposeful copy. No exclamation points.

### Aesthetic Direction
Dark mode only. Violet glass-morphism on near-black surfaces. The palette is Material 3-derived but applied with restraint.

**Reference products:**
- **Kimi** — Clean conversation flow, structured responses, elegant assistant presence, uncluttered sidebar
- **Claude.ai** — Warmth inside a technical context, readable prose at scale, tasteful accent color usage
- **Vercel dashboard** — Data density done right; sharp typography; purposeful negative space; confidence without clutter

**Anti-references (what Hermes must NOT be):**
- Generic chatbot UI (floating message bubbles, consumer-grade send buttons, chat-app chrome)
- Consumer or playful (rounded-everything, gradient blobs, approachable-soft aesthetics)
- Classic ChatGPT gray: sterile gray-on-gray, no visual hierarchy, zero brand identity

### Design Principles

1. **Signal over noise** — Every element earns its place. Decoration that carries no meaning should be removed. Complexity is tolerated only when it reveals information.

2. **Calm confidence** — The interface projects control and reliability. No jarring transitions, no competing focal points, no aggressive motion. Activity indicators are subtle; urgency is conveyed through state, not animation speed.

3. **Density with breathing room** — Hermes users are power users. Information can be dense, but never cramped. Generous line-height (`leading-relaxed`), clear groupings, and consistent 8px-grid spacing prevent cognitive overload.

4. **The swarm is alive** — Agents have states, relationships, and ongoing activity. The visual system must make agent status and topology legible at a glance. Active ≠ idle should be instantly clear without reading labels.

5. **Glass as depth, not decoration** — Glass-morphism is reserved for genuine layering (panels floating over dark surfaces). It is not a style applied arbitrarily. Max 2 active blur layers per screen.

### Accessibility Baseline
WCAG 2.1 AA. Violet primary (`#e0b6ff`) on dark backgrounds meets contrast requirements. All interactive elements have visible focus rings (`focus-visible:ring-2 focus-visible:ring-primary`). `prefers-reduced-motion` is respected — all animations pause.
